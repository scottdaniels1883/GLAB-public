Install a game on your phone

  1. Tap a game above to open it.
  2. iPhone: in Safari, tap the Share button, then Add to Home Screen.
  3. Android: in Chrome, tap the menu (⋮), then Install app.
  4. Open it once from the new icon while online. After that it works anywhere.
